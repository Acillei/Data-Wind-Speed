# Phân Tích Dữ Liệu Khí Tượng: Biến Động Sức Gió Miền Trung (2005-2025)

## Dưới đây là danh sách liệt kê các thành phần trong thư mục mã nguồn của dự án và ý nghĩa của từng tệp:

**POWER_Point_Daily_20050101_20251231_016d07N_108d22E_LST.csv:**  File chứa tập dữ liệu gốc 20 năm về vi khí hậu miền Trung Việt Nam được trích xuất từ hệ thống NASA POWER.

**Metadata_NASA_BaoMienTrung.txt:** File siêu dữ liệu (Metadata) đi kèm, dùng để giải thích chi tiết ý nghĩa các biến số, đơn vị đo lường và ký hiệu giá trị lỗi/khuyết thiếu (-999.0) của tập dữ liệu.

**Data_Analysis_BaoMienTrung.ipynb:** File mã nguồn Python (Jupyter Notebook) chứa toàn bộ quá trình thực thi: tiền xử lý làm sạch dữ liệu, trực quan hóa biểu đồ và chạy kiểm định thống kê phi tham số Mann-Whitney U.

**Data Management Plan - DMP.docx:** File Kế hoạch Quản lý Dữ liệu, làm minh chứng cho việc dự án tuân thủ nghiêm ngặt 4 nguyên tắc dữ liệu mở FAIR (Findable, Accessible, Interoperable, Reusable).

**POSTER A1.png:** File hình ảnh poster khổ A1 trực quan hóa tóm tắt lại toàn bộ quá trình nghiên cứu, biểu đồ và các kết luận cốt lõi của đề tài.
